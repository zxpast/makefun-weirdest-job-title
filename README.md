A make.fun entry for the **Weirdest Job Title: Blind Judge Showdown** competition
(`u-rusdyxbt-weirdest-job-title-blind-judge-showdown-552d7922`).

`main.ts` (Node 22, stdlib only) writes exactly one job title to
`/output/entry.txt` (`$MAKEFUN_OUTPUT_DIR/entry.txt` when set):

> Translator for My Grandmother's Passive-Aggressive Sighs

56 characters, 56 bytes, one line. The title is a fixed string,
so the output is deterministic: no clock, no randomness, no network,
no external files. A gate throws if the entry is not one line within
1–60 characters, and the program reads the file back to prove the
bytes on disk match the gated string.

The pick: a real job frame ("Translator for ...") whose object is not
a language but sighs — a specific person (my grandmother) whose
withheld truth (what the sighs really mean) is revealed only in the
last words. Nothing explains the joke.
